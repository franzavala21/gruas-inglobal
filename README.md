# Inglobal · Prototipo de sistema

Prototipo navegable del sistema de gestión para Inglobal (grúas, hidrogrúas y maquinaria industrial, Córdoba).

Ingresar con cualquiera de los usuarios de prueba (contraseña `inglobal`). Todos los datos son ilustrativos y nada se guarda al recargar.
